# One band per Band line, fields split by |:
#   Band: start_hz | end_hz | listen_hz | label | typical use | limit
# listen_hz is where the receiver parks to check the band; empty means the middle.
# Only bands the CC1101 can tune are listed (300-348, 386-464, 778-928 MHz; with Extended
# Sub-GHz on 281-361, 378-481, 749-962 MHz). Part 15.231 covers 260-470 MHz outside the
# restricted bands; the rows below are the parts of it the radio reaches, split where a
# restricted band (15.205: 322-335.4 and 399.9-410 MHz) or the radio's own gap cuts it.
#
# Part 15 writes these limits as field strength at 3 m, not as power, and so does this file.
# 15.231(b) runs from 3,750 uV/m at 260 MHz to 12,500 uV/m at 470 MHz in a straight line;
# the per-frequency figures below are worked out from that line.
#
# A firmware update puts the shipped files back as they were, so edit a copy, not this file.
